# 海外交流模板：章節、表格與人員名冊

本模板從實際提案的內容結構整理而成，用於準備或檢查整份海外交流企劃，以及處理人員名冊與分工。舊提案的欄位是模板依據，當次官方簡章與指定表格才是申請規則。只修改單一段落時，維持使用者要求的範圍。

## 先把內容對應到當次格式

有官方格式時，保留原欄位、順序與篇幅，將下表內容放進對應欄位或指定附件。若姓名、履歷、經費等另有專用表單，記錄其位置，不重複加進受限篇幅的計畫正文。沒有官方格式時，可用下表順序作為工作稿架構，並標示送件格式尚待確認。

準備整份時，簡要記錄「內容項目／官方欄位或附件位置／依據為官方要求或模板建議／已有內容或待補」。官方要求的項目全部保留；其他項目依本案適用性合併或標示不適用及理由。這份清單用於檢查，不自動加成送件附件。

| 內容項目 | 應處理的資訊 | 配置方式 |
|---|---|---|
| 計畫基本資料 | 計畫名稱、申請人或單位、目的地、執行期間、實際出國人數 | 已有申請表時沿用其欄位 |
| 計畫目的 | 本次要推進的創作或專業工作、交流目的 | 與可執行工作對應 |
| 背景與動機 | 已有經驗、現階段問題、為何選此機會 | 可與目的合併，保留各自要回答的內容 |
| 主辦／邀請／合作單位簡介 | 各單位角色、相關資源與合作狀態 | 不能將所有單位都寫成主辦方 |
| 申請人或團隊簡介 | 與本次交流有關的經歷、作品及原有角色 | 可對應履歷附件；與出國名冊功能不同 |
| 參與內容與執行方式 | 參與形式、工作、場次、地點、所需設備與交流對象類型 | 多階段分開交代；個人駐村則對應進駐計畫欄 |
| 分日行程 | 日期、地點、當日工作與交通安排 | 已知範圍填入，未公布的排程標待確認 |
| 參與人員名單／出國人員名冊與分工 | 誰實際出國、每人身分、工作與經歷 | 每案都核對；依下節決定使用獨立名冊或既有個人欄位 |
| 行銷宣傳與回饋 | 本次出訪如何紀錄、向誰分享、返國後安排 | 官方要求時保留；其他情況依計畫需要與成果欄整合 |
| 預期成果與效益 | 可交付成果、專業發展、後續運用與回饋 | 保留已確認與規劃中的區別 |
| 經費與資金來源 | 支出明細、本次申請額、自籌、其他資金及主辦方支持 | 依當次格式；定額或無須自編預算者不強加自提預算表 |
| 佐證與其他附件 | 邀請、履歷、作品、合作或資格證明等適用材料 | 依官方清單逐項記錄已提供、待補或未檢視 |

## 人員名冊：具體欄位

先區分「本次出國者」「留臺支援者」「當地合作方或導師」。申請單位、全體製作團隊與實際出國者可能不同；製作名單或邀請函出現的人名，都不能直接當成已確認出國者。只知道角色而不知道人選時，保留「人選待確認」，不取虛構姓名。

自由格式的海外交流工作稿預設保留「出國人員名冊與分工」。一人出國也要明確列出；固定個人申請表已有姓名、簡介與履歷時，核對這些欄位及計畫中的本人工作即可，無須新增獨立章節。

| 欄位 | 填寫規則 |
|---|---|
| 中文姓名 | 沿用使用者為本次申請提供的姓名；未知標待補 |
| 護照英譯名 | 當次表格要求時保留。按使用者提供的護照拼寫原樣填入；不能自行音譯，也不把一般英文暱稱當成護照姓名 |
| 職稱／本案角色 | 如導演、製作人或表演者，依已知資料；原任職稱與本案角色不同時分清楚 |
| 本次職責 | 具體寫出本人負責的工作，如作品發表、技術架設、交流聯繫或排練；不能只列頭銜 |
| 相關經歷簡介 | 選擇能支持本次工作的經歷，保留年份、作品或單位及本人角色；未知經歷不補寫 |
| 參與階段與期間 | 多次出國、各人期間不同時分別標示；全員同程可共用清楚註記 |

上表是可用欄位，是否為官方必填需逐項核對。自由格式初稿尚未確認英譯名要求時，可先在待補清單標「護照英譯名是否需填：待查本次格式」，不宣稱所有補助都要求。原稿使用的人像照片、獎項數量或履歷長度不沿用為固定門檻；照片依官方要求或使用者提供與選擇處理。

簡單名冊可使用可編輯表格；經歷較長時，可每人一段，依序列「姓名與角色／本次職責／相關經歷／參與期間」。官方欄位名稱優先。不要為了把所有內容擠進一列而做成難以閱讀的寬表。

名冊資料不足時，仍在工作稿的對應位置保留欄位與待補標記，並在交付訊息另列缺口。未知總人數不擅自設為一人或以資料筆數代替；先完成有根據的部分，再詢問影響人數或分工的關鍵缺口。

## 與行程、邀請及經費一起核對

- 以實際不同的人計算出國人數；同人兼任多個角色、參加多個階段不重複算成多人。需要人次時另列定義與計算。
- 逐階段對應每人的日期、目的地、工作與必要的交通及住宿。不同人可以不同時間出返國；不要自動套用同一趟行程。
- 邀請函若僅邀請部分人，標出其餘人員的參與依據或待確認狀態，不推定全員受邀。
- 經費按「人員／階段／項目／數量與單位／負擔來源」追溯。機票張數可能是航段或來回票，不能直接當作出國人數；住宿房數、晚數與人數也須分別判斷。
- 出國人數可以大於本次申請補助的人數。先查主辦方支付、自籌或其他來源及申請範圍，再判定是否漏編；不要為了人數一致擅增費用。

計算與資金適用性另見 [一致性與經費檢查](review.md)。

## 兩種寫法共用的交付規則

段落骨架將動機、概念與效益等論述做成可擴寫的骨架；姓名、職責、行程和經費等事實依已知資料直接列入表格。內文方式直接撰寫論述，並保留相同的事實表格。兩種都不能只留下「請補人員介紹」而省掉名冊應有的欄位。

交付整份 Word 前確認：人員資料已實際放在對應章節或指定表單；名冊與工作安排、經費範圍對得上；官方必要欄位仍有缺漏時，保留位置並列待補。使用者只要求排版現有稿件時，保留原文並指出缺漏，未授權補寫的內容不自動加入。
