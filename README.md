## 台灣藝文補助 AI 企劃助手

把補助申請的寫作經驗整理成可重複使用的AI Skills，陪你從簡章、資料與段落骨架，逐步完成企劃。

### 分享包裡有什麼？

**企劃寫作助手 `taiwan-art-grants`**

依當次簡章整理申請架構，對照作品筆記、履歷或邀請文件，標示待補內容。海外交流會一併核對人員名冊與分工、行程、經費及附件；官方表格已有對應欄位時沿用原位置。

**中文修飾助手 `zh-direct-prose`**

減少AI常見的句型，用中文直述句表達。保留原意、事實、語氣與「預計／待確認」等狀態。

這份Skills已整理好寫作流程與檢查重點，你可以重複使用，不用每次從頭教AI怎麼協助準備藝文補助企劃。

### 你可以選擇怎麼寫

| 寫法 | AI 做什麼 | 你做什麼 |
|---|---|---|
| **列出段落骨架，自己擴寫** | 先列每段的用途和一句話重點 | 把重點寫成完整段落，保留自己的文字風格 |
| **先寫內文，我來修改** | 依已有資料形成草稿，未知內容標待補 | 核對事實、補齊內容並調整語氣 |

兩種方式都適用創作徵件與海外交流，可以中途更換，也可以只讓某一段換寫法。名冊、行程和經費等事實表格會依已知資料整理。

### 安裝後怎麼開始？

1. 準備簡章、官方範本（如果有的話）及作品資料；海外交流另準備邀請文件、行程與出國人員資料。
2. 啟用技能，告訴AI你要申請什麼，以及想採用哪種寫法。
3. 依整理結果逐步補資料、寫作、修訂與檢查。
4. 需要Word時，請AI運用目前環境的檔案功能產出可編輯的 `.docx`，下載後再確認內容與版面。

你可以這樣開始：

> 請使用企劃寫作與中文修飾Skills。這是本次簡章與我的作品資料。我想先列出段落骨架，自己擴寫。請依官方欄位整理每段要回答什麼、可以使用哪些已知素材，缺少的資料標為待補。

想先看草稿時：

> 請依這份簡章和我提供的資料，先寫內文，我來修改。尚未確認的人員、行程、合作或金額請標為待補，不要自行補述。

### 使用前知道這幾件事

- Skills提供寫作與檢查方法，實際申請依當次官方簡章與格式處理，不保證補助結果。
- Word輸出需要目前的AI環境具有文件製作功能；交付前仍需核對事實、必填欄位、附件及版面。
